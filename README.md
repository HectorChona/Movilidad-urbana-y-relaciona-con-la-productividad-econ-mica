# Movilidad-urbana-y-relaciona-con-la-productividad-econ-mica
El objetivo fue  evaluar cómo la movilidad urbana se relaciona con la productividad económica en las principales ciudades latinoamericanas.  Se limpiaron, combinaron y analizaron dos bases de datos reales para identificar en qué ciudades conviene invertir en infraestructura de transporte.
